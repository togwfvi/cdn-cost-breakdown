## CDN费用有哪些：七项费用一次列清

先给结论表。七项费用里，流量费永远是最大头，其余六项在不同业务里的占比差异极大——API站怕请求费，缓存命中率低的站怕回源费，源站在对象存储上的还要多交一笔出口费。

| 费用类型 | 怎么算 | 什么情况下是大头 | 参考价位（已核验） |
| --- | --- | --- | --- |
| 流量费 / 带宽费 | 按下行流量每GB计，或按带宽峰值计 | 几乎所有站点 | 欧美首档 $0.005–$0.12/GB |

表里的价位取自各厂商官网2026年核验的公开价目，区域和用量档位不同会有浮动，但方向是可靠的。

## 流量费：单价为什么能差出24倍

欧美首档流量单价从低到高排：Bunny.net的Volume网络 $0.005/GB、Bunny Standard $0.01/GB、Google Cloud CDN $0.08/GiB、Azure Front Door $0.0825/GB、AWS CloudFront $0.085/GB、Fastly $0.12/GB。最低和最高之间正好24倍。

便宜的那档有代价。$0.005 是 Bunny 的 Volume 网络，全球只有10个节点；要用119个节点的Standard网络，单价就是$0.01。节点少意味着边缘服务器离部分用户更远，速度和命中率都会受影响，比价之前先看节点覆盖。

Cloudflare是另一种模型：所有套餐带宽不限量，只收固定月费——Free、Pro $25/月、Business $250/月，年付大约省20%（$20和$200）。内容能被完整缓存的站点，这套模式在大流量下基本碾压所有按GB计费的方案；反过来，动态请求多、缓存率低的话，优势就没那么明显。

计费模式大体三种：按GB阶梯计价（CloudFront、Fastly、Bunny、Google Cloud CDN）、套餐包月（Cloudflare这类）、固定月费加按GB（Azure Front Door）。同样跑10TB/月，把免费额度和基础费都算进去：Bunny Volume约$51.20，Google Cloud CDN约$763，CloudFront约$783，Azure Front Door约$880，Fastly约$1,217。账单排名和单价排名并不一致，这个例子够直观了。

## 区域加价：用户落在哪，比首页报价更重要

厂商首页挂的几乎都是欧美价。亚洲通常是欧美的1.5到2倍，中东和非洲2到3倍，南美居中。几个已核验的例子：Fastly欧美$0.12，亚洲$0.19，非洲和印度$0.28；Bunny Standard欧美$0.01，亚洲$0.03，中东非$0.06。KeyCDN分三个价格区，同样200TB流量，落在不同大洲的账单分别是$3,600、$7,200和$11,200。

选型的正确顺序是先看用户地区分布，再回头比单价。监控里八成流量来自亚太，就得用亚太价重算一遍，首页那个欧美数字对你没什么意义。

## 请求费与HTTPS请求：小站没感觉，API站要盯紧

按每万次请求收费是行业惯例：AWS CloudFront每万次$0.0075到$0.01，Azure Front Door $0.009，Fastly $0.01，Google Cloud CDN对缓存查找另收每万次$0.0075。普通图文站流量小时这部分可以忽略，一个月多不了几块钱。

API站和小图多的站是另一回事：响应体小，请求数远超流量直觉，请求费在账单里的占比会明显抬升。HTTPS请求在很多厂商是单独的计费类目，阿里云CDN也是把HTTPS请求数放在流量之外单独计算，动态内容的请求则走全站加速（DCDN）另行定价。开通前把这几项的单价翻出来看一眼，比月底看账单舒服。

## 回源与缓存未命中：命中率低，等于把流量费交两遍

正常情况下CDN只收边缘到用户的流量；缓存未命中时CDN要先回源拉内容，这笔回源流量在部分厂商那里同样要钱。Google Cloud CDN是典型：未命中时收$0.01/GB的缓存填充费，边缘到客户端照常计费，缓存查找还要另付钱。命中率低，同一段内容就交两遍流量钱——专门做CDN比价的cdncost算过，低命中率能让成本直接翻倍。

还有个换算陷阱：Google按GiB计费，1 GiB约合1.074 GB。拿$0.08/GiB直接对比别家的$0.08/GB，会把Google高估7%左右，换算后再比才公平。

提高命中率通常比换厂商更省钱：把静态资源的缓存头设长一些，用Origin Shield这类回源收敛功能（CloudFront的Origin Shield就是干这个的）。命中率从80%提到95%，回源相关的开支直接砍掉四分之三。

## 月费、免费额度与起步成本

对低流量站来说，固定支出比单价更能决定账单。Azure Front Door收$35/月的Standard基础费（$330的Premium捆绑了WAF），月流量不大时这笔钱比流量费还显眼。免费额度这边：AWS CloudFront每月1TB流量加1000万次请求长期免费，Fastly每个区域每月前100GB免费，Bunny最低消费$1/月，Cloudflare免费版连带宽都不限量。

免费额度会直接改写排名：月流量1TB以内，CloudFront的实际支出是0；冲过10TB之后，按量厂商之间的单价差才重新主导账单。起步阶段和成熟阶段适合的厂商经常不同，隔几个月拿真实用量重算一次是必要动作。

签约前还有三件事值得查。一是报价方式：Akamai、Azure Front Door企业量都不挂公开价目表，拿不到书面费率就没有谈判底线，Cloudflare企业版外界普遍说法是每月5,000美元左右起步。二是厂商还活着没：Edgio和StackPath都已停业，Azure CDN Standard官宣2027年9月30日退役，签约等于赌这家公司能陪你到合同到期。三是增值功能：WAF、Bot管理、图片优化在Cloudflare Business及以上之外的几乎所有厂商都要单独购买，Cloudflare Argo、AWS Global Accelerator这类高级路由则常埋在企业报价里，问清再签。

## 最容易漏掉的一笔钱：源站出口流量费

CDN账单之外，源站所在的云还会按GB收出口流量费。数据从S3、EC2或GCS流向一家非同家的CDN，大约$0.05–$0.09/GB，直接出现在云账单上。

这笔钱专治一种省钱计划：把CDN从CloudFront换成更便宜的厂商，源站还留在S3上。CDN侧省下的差价，可能还不够付S3的出口费。AWS自家组合没这个问题——S3到CloudFront的回源流量免费，这也是源站在AWS时CloudFront往往是默认答案的原因。算总账时把“源站到CDN”这一段加进去，再和CDN单价比。

## 几个高频问题

**10TB流量一个月大概花多少钱？**

**有没有不限流量的CDN？**
Cloudflare，所有套餐带宽不限量，只收固定月费（Free $0、Pro $25/月、Business $250/月）。前提是内容能被缓存，动态请求占比高的站点优势会缩小。

看流量曲线。突发明显的选按流量；全天平稳的业务拿峰值数据两边各算一遍，平稳曲线通常按带宽峰值更省。
